# Retired growth-calibration category

Explicit user direction retired the entire adult-size/manual-growth-pulse versus fixed-reference
calibration category, including v1, v2, optional endpoint probes and associated diagnostics,
prototype/full/control campaigns and calibration-only qualification guards.

These authored files are preserved history, outside active source compilation, Gradle source-set
registration and unittest discovery. They are not supported executable entry points, required
fixtures, acceptance gates or prerequisites for stable Dist. Do not launch or restore them.
Associated development worlds, logs, raw timing, failed campaigns, receipts and SDK outputs remain
retained in their original evidence locations; retirement does not delete or reinterpret them.

Active verification retains 25 native functional cases, including real normalized cadence,
constant rates/energy/taper, persistence, optional product/geometry behavior and absence safety.
Production `TreeGrowthRates` data and all gameplay rates/references are unchanged. No historical
failure is newly called a pass, and no calibration result or v2 promotion is claimed.
